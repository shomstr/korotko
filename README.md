# Барбершоп КОРОТКО / АМГ — онлайн-запись

Веб-приложение для онлайн-записи в барбершопы **АМГ** и **КОРОТКО** (Казань). Написано на Python + Flask + SQLite3, фронтенд — ванильные HTML/CSS/JS (киберпанк-стиль).

## Возможности

- Каталог услуг с ценами и длительностью (основные и дополнительные).
- Выбор филиала (АМГ / КОРОТКО), даты и свободного слота.
- Онлайн-запись: имя, телефон, email, согласия на обработку данных и рассылку.
- Личный кабинет клиента: просмотр своих записей по номеру телефона, оценка прошедших визитов (1–5 звёзд).
- Админ-панель:
  - дашборд (кол-во пользователей, записей, последние записи);
  - управление пользователями (поиск, детали, удаление);
  - рассылка по email (через SMTP Яндекс.Почты) подписчикам, давшим согласие.
- Бронирование с защитой от пересечения: между записями обязателен буфер 15 минут.
- Развёртывание через Docker + nginx.

## Запуск

### Локально (без Docker)

Требуется Python 3.10+.

```bash
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python app.py
```

Приложение будет доступно на `http://localhost:8000`.

Порт можно переопределить переменной окружения:

```bash
PORT=8080 python app.py
```

### Docker

```bash
docker compose up -d --build
```

Сервис будет слушать `127.0.0.1:8000`. База данных сохраняется в docker-volume `korotko_data` (файл `/app/data/korotko.db` внутри контейнера).

### Продакшен (nginx)

1. Скопируйте `nginx/barber-parik.conf` в конфиги nginx и подключите сайт.
2. Укажите нужный `server_name` (сейчас `barber-parik.online`).
3. nginx проксирует запросы на `127.0.0.1:8000`, где работает Flask (в контейнере или локально).
4. Не забудьте настроить TLS (certbot / Let's Encrypt).

## Использование

### Клиент

- **Главная** (`/`): список услуг и цен, контакты обоих филиалов, кнопка «Записаться».
- **Запись**: выбрать филиал → услугу → дату → свободное время → заполнить имя/телефон/email → отметить согласие с политикой → «Записаться».
- **Профиль** (`/profile`): вход по номеру телефона, просмотр записей, оценка прошедших визитов.

### Админ

- Адрес: `/admin` (или `/admin/login`).
- **Дефолтный логин/пароль**: `admin` / `admin`. При первом входе система заставит сменить пароль.
- Разделы:
  - **Дашборд** — статистика и последние записи.
  - **Пользователи** — поиск, детали (все записи клиента), удаление.
  - **Рассылка** — настройка SMTP Яндекс.Почты (email и пароль приложения), тестовое письмо, отправка рассылки подписчикам.

## API

| Метод | URL                | Описание                                          |
|-------|--------------------|---------------------------------------------------|
| GET   | `/api/services`    | Список услуг (JSON)                               |
| GET   | `/api/slots?service_id=&date=&address=` | Свободные слоты на дату (JSON)    |
| POST  | `/api/book`        | Создание записи (JSON)                            |
| POST  | `/api/rate`        | Оценка прошедшей записи (JSON)                    |

Пример создания записи:

```bash
curl -X POST http://localhost:8000/api/book \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Иван",
    "phone": "+79963375570",
    "email": "ivan@example.com",
    "service_id": 1,
    "date": "2026-08-20",
    "time": "14:00",
    "address": "amg",
    "consent_policy": 1,
    "consent_mailing": 0
  }'
```

## База данных (SQLite)

Схема создаётся автоматически при старте (`init_db()` в `database.py`).

- `users` — клиенты: id, name, phone (уникальный), email, consent_policy, consent_mailing, created_at.
- `services` — услуги: id, name, price, duration_min, category (`main`/`extra`), description.
- `bookings` — записи: id, user_id (FK), service_id (FK), start_time, end_time, address, status (`active`), rating, comment, created_at.
- `admins` — администраторы: id, username (уникальный), password_hash, must_change_password.
- `settings` — ключ/значение (например, `yandex_email`, `yandex_password`).

Сиды при первом запуске: 7 услуг и админ `admin` / `admin`.

## Редактирование проекта

### Главная страница, контакты, филиалы

- **Филиалы и их адреса** — словарь `ADDRESSES` в `app.py` (строки 18–21). Здесь же рабочие часы каждого филиала. Добавление нового филиала = новая запись в словаре + карточка в `templates/index.html`.
- **Контакты, телефоны, ссылки, карты** — разметка в `templates/index.html` (секция `#contacts`).
- **Услуги** — либо правка сида `seed_services` в `database.py`, либо напрямую в таблицу `services` (тогда пересоздание БД не потребуется). Цена и длительность подтягиваются автоматически.

### Логика записи

- **Рабочие часы** — `ADDRESSES` в `app.py` + константы `WORK_START`/`WORK_END` (app.py:36-37).
- **Буфер между записями (15 мин)** — `get_available_slots` (app.py:114) и `check_booking_conflict` (database.py:140).
- **Нормализация телефона** — `normalize_phone` (app.py:27).

### Почта (рассылка)

- Настройки SMTP Яндекс.Почты хранятся в таблице `settings` (ключи `yandex_email`, `yandex_password`) и редактируются в админке `/admin/mailing`.
- Отправка — `send_email_smtp` (app.py:43). Используется `smtp.yandex.ru:465` (SSL).

### Стиль и внешний вид

- **Палитра, шрифты, отступы** — `static/css/style.css`.
- **Формы, маска телефона, валидация, загрузка услуг/слотов** — `static/js/main.js`.
- **Разметка публичных страниц** — `templates/*.html`.
- **Шаблоны админки** — `templates/admin/`.

### Безопасность

- Пароли хешируются через `werkzeug.security` (`generate_password_hash` / `check_password_hash`).
- Все SQL-запросы параметризованные — защита от SQL-инъекций.
- Админ-роуты защищены декоратором `@admin_required`.
- `app.secret_key` генерируется случайно при каждом старте — сессии клиентов сбрасываются при перезапуске.

### Конвенции при разработке

- Если вносите изменения в логику БД — обязательно используйте параметризованные запросы (`?`).
- Код-стайл: Python (Flask), шаблоны Jinja2, ванильный JS.
- Перед изменением БД помните: `init_db()` применяет миграции через `ALTER TABLE ... ADD COLUMN` с обработкой ошибки, если колонка уже существует.

## Частые операции

### Сбросить пароль админа

Удалить файл `korotko.db` (потеряются все данные) или выполнить в консоли:

```bash
sqlite3 korotko.db "UPDATE admins SET password_hash = '...', must_change_password = 1 WHERE username = 'admin';"
```

(хеш должен быть сгенерирован через `werkzeug.security.generate_password_hash`).

### Добавить услугу без пересоздания БД

```bash
sqlite3 korotko.db "INSERT INTO services (name, price, duration_min, category, description) VALUES ('Стрижка машинкой', 450, 30, 'main', 'стрижка, укладка');"
```

### Посмотреть записи

```bash
sqlite3 korotko.db "SELECT * FROM bookings ORDER BY start_time DESC LIMIT 20;"
```
