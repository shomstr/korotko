Ты — разработчик админ-панелей. 

## Функционал
1. **Авторизация**: Простая форма входа. Дефолтный логин/пароль: `admin` / `admin` (при первом входе система должна требовать смену пароля).
2. **Дашборд**: Общее количество пользователей, общее количество записей.
3. **Управление пользователями**: Таблица с поиском. Столбцы: ID, Имя, Телефон, Email, Кол-во записей. Кнопки: "Просмотреть детали", "Удалить" (с подтверждением).
4. **Рассылка**: Форма с полями "Тема" и "Текст". При отправке бэкенд собирает все email из таблицы `users` (у которых есть согласие на рассылку) и отправляет письма.

## Безопасность админки
- Все роуты админки начинаются с `/admin/`.
- Доступ только для авторизованных администраторов.
- Удаление пользователя должно быть каскадным или мягким (soft delete), чтобы не ломать историю записей.
